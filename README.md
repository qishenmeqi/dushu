# 读书

拍一页书，原样显示在屏幕上，点图上任意一句，就用中文女声念给你听。看不懂的字词也能查。

## 怎么用

1. 双击 **启动.bat**
2. 浏览器会自己打开 `http://localhost:5180`（没打开就手动输一下）
3. 点「拍一页」，对着书页拍一张，或者从相册里选图
4. 页面的原图会直接显示出来，点图上任意一句话，就从那句开始读

想接着拍下一页，点阅读区上方的「＋ 加一页」。

不管是纯文字的页面，还是有插图的页面，都是直接显示你拍的原图，朗读的是图上识别出来的文字，不会再换成纯文字排版。

## 查字词

- 点「＋ 加一页」旁边的「查词」，输入一个词，能看到拼音、意思和例句
- 查词框右边的麦克风可以说话查词，语音识别在本机跑，不联网
- 词卡上的「读一遍」会用同一个女声读一遍
- 词典里没有整个词时，会把里面的字一个个拆开解释

**注意**：现在是图片模式，图上的字是像素，没法像网页文字那样用鼠标划选。要查词请用「查词」按钮。

另外，这里查的是字词的意思，不会解释整句话讲了什么，也不会回答内容问题。

## 手机上用

手机和电脑连同一个 WiFi，在电脑上启动以后，黑色窗口里会列出手机能打开的地址，比如：

```
http://192.168.1.8:5180
```

在手机浏览器里输入这个地址就行。手机上点「拍一页」会直接调出相机。

**手机上的语音输入要 https 才行**，浏览器只允许安全页面用麦克风。本地这个 http 地址在手机上打不开麦克风，电脑上用 `localhost` 可以。放到 GitHub Pages 上就有了 https，手机上也能用语音。

## 建议

- 拍照的时候镜头正对书页，书放平，光线均匀，别让手或阴影挡住字
- 拍歪了、光线不匀时，图上标出的句子位置可能不太准，但朗读的文字一般够用
- 进度会自动存着，关掉再打开还能接着读
- 页面存在浏览器本地（IndexedDB），换浏览器或清站点数据会丢

## 设置的几个东西

- **朗读声音**：固定为华言，离线的中文女声
- **语速**：0.5 到 2 倍，改了以后下一句生效
- **朗读时滚到当前句**：关掉的话页面不会自己滚动
- 播放时点图上任意一句，会从那一句开始往下读
- 键盘：空格播放/暂停，左右方向键上一句/下一句

## 隐私

照片、词典、语音识别、朗读合成，全部在这台设备的浏览器里完成，不联网、不上传。文字和进度存在浏览器的本地存储里，重要的内容可以「下载 txt」存下来。

## 已知的限制

- 图上的字不能划选，查词要用「查词」按钮
- 竖排的古籍、手写体、字特别小的书，识别率会明显下降
- 识别出来的字偶尔有错，朗读时按错的读；图片本身不受影响
- 词典覆盖常见字词和成语，生僻词查不到时会拆字解释
- 语音识别对安静环境、普通话效果好；生僻词可能认错，认错了直接在框里改
- 朗读是本地神经网络合成的：第一次点播放要加载十几秒，之后每句合成一两秒，下一句会提前合成，连续听基本不断
- 页面图片存在浏览器里，几十页没问题；拍得太多会占空间，可以「清空全部」重来

## 文件

```
index.html     页面结构
style.css      样式
app.js         全部逻辑（拍照、识别、图上点击、朗读、查词、语音）
server.js      本地小服务器，只是把文件发给浏览器
启动.bat        双击启动
vendor/        本机用的数据，不用联网下载
  tesseract...   文字识别引擎
  tessdata/      中文识别包（best 版，11MB）
  dict/          离线词典（字、词、成语，14MB）
  pinyin-pro.js  拼音
  vosk/          离线语音识别（库 + 中文模型 42MB）
  piper/         离线语音朗读（引擎 + 华言女声，约 155MB）
```

纯静态网页，没有构建步骤，也没有后端。以后放到 GitHub Pages 上，手机上直接打开网址就能用。
