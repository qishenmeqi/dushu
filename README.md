# 读书

拍一页书，认出文字，用中文语音一句一句念出来。看不懂的字词，选中就能查意思和读音。

## 怎么用

1. 双击 **启动.bat**
2. 浏览器会自己打开 `http://localhost:5180`（没打开就手动输一下）
3. 点「拍一页」，对着书页拍一张，或者从相册里选图
4. 等识别完，点底部的播放键，就开始读了

想接着拍下一页，点阅读区上方的「＋ 加一页」。

## 查字词

- 在书里选中一个字或词（最多 8 个字），松开后会浮出一个「查」，点它就能看到读音和意思
- 也可以点「＋ 加一页」旁边的「查词」，直接打字查
- 查词框右边有个麦克风，点一下开始说话，再点一下结束，会自动把说的话变成文字去查。语音识别在本机跑，不联网
- 词典里没有整个词时，会把里面的字一个个拆开解释
- 词卡上的「读一遍」会用当前的音色读一遍

这里要说明白：**「查」是查字词的意思，不会解释整句话讲了什么，也不会回答内容问题**。那需要语言模型，这版没有接。

## 手机上用

手机和电脑连同一个 WiFi，在电脑上启动以后，黑色窗口里会列出手机能打开的地址，比如：

```
http://192.168.1.8:5180
```

在手机浏览器里输入这个地址就行。手机上点「拍一页」会直接调出相机。

**手机上的语音输入要 https 才行**，浏览器只允许安全页面用麦克风。本地这个 http 地址在手机上打不开麦克风，电脑上用 `localhost` 可以。以后放到 GitHub Pages 上就有了 https，手机也能用。

## 添加到主屏幕

用手机浏览器打开线上地址 `https://qishenmeqi.github.io/dushu/`：

- iPhone：Safari 打开，点分享 → 「添加到主屏幕」
- 安卓：Chrome 打开，右上角菜单 → 「安装应用」或「添加到主屏幕」

添加后从主屏幕点开是全屏的，没有地址栏。如果之前加过旧图标，先删掉再重新添加。

线上第一次识别要下载约 6MB 识别包，页面上会显示下载百分比。线上语音包有 155MB，不建议在线上听朗读。

## 建议

- 朗读用的是本机的离线语音包（华言女声），浏览器用哪个都行，不再依赖系统音色
- 拍照的时候镜头正对书页，书放平，光线均匀，别让手或阴影挡住字。
- 识别出来的字可以直接改：设置 → 编辑文字。
- 进度会自动存在浏览器里，关掉再打开还能接着读。

## 设置的几个东西

- **朗读声音**：固定为华言，离线的中文女声，不用挑
- **语速**：0.5 到 2 倍，改了以后下一句生效
- **朗读时滚到当前句**：关掉的话页面不会自己滚动
- 播放时点任意一句，会从那一句开始往下读
- 键盘：空格播放/暂停，左右方向键上一句/下一句

## 隐私

照片、词典、语音识别、朗读合成，全部在这台设备的浏览器里完成，不联网、不上传。文字和进度存在浏览器的本地存储里，换浏览器或清缓存会丢，重要的内容可以「下载 txt」存下来。

## 已知的限制

- 竖排的古籍、手写体、字特别小的书，识别率会明显下降
- 拍照有透视变形、光线不匀时，识别出来的字会有错，听的时候影响不大，需要的话可以手动改
- 词典覆盖常见字词和成语。生僻词、专有名词查不到时会拆字解释
- 单字释义里有不少古文引证，卡片默认只显示前面一段，点「展开全文」看全部
- 语音识别对安静环境、普通话效果好；生僻词可能认错，认错了直接在框里改
- 朗读是本地神经网络合成的：第一次点播放要加载十几秒，之后每句合成一两秒，已经有了下一句的预取，连续听基本不断
- 手机锁屏后很多浏览器会停掉播放，想一直听就让屏幕亮着

## 文件

```
index.html     页面结构
style.css      样式
app.js         全部逻辑（拍照、识别、断句、朗读、查词、语音）
server.js      本地小服务器，只是把文件发给浏览器
启动.bat        双击启动
manifest.webmanifest  主屏幕应用的配置
sw.js          页面外壳的离线缓存
icons/         应用图标
vendor/        本机用的数据，不用联网下载
  tesseract...   文字识别引擎
  tessdata/      中文识别包（best 版，11MB）
  tessdata-fast/ 线上用的精简识别包（1.7MB）
  dict/          离线词典（字、词、成语，14MB）
  pinyin-pro.js  拼音
  vosk/          离线语音识别（库 + 中文模型 42MB）
  piper/         离线语音朗读（引擎 + 华言女声，约 155MB）
```

纯静态网页，没有构建步骤，也没有后端。以后放到 GitHub Pages 上，手机上直接打开网址就能用。
